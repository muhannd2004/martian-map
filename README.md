# Martian Map
ARES-NAV is an interactive mission planning and terrain analysis platform designed for exploring the Jezero Crater on Mars. The application provides high-resolution orbital basemaps, topographic analysis, surface temperature data, and intelligent route planning to compute safe traverse paths across rugged Martian terrain.
